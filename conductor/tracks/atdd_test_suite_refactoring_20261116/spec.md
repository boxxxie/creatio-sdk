# Track Specification: ATDD Test Suite Refactoring, Matrix Consolidation & Regression Deduplication

## Overview
The `creatio` test suite currently contains `408` active ExUnit tests (`418` including `@moduletag :live`) across `10,599` lines in `test/` and `test/support/`. An audit of the test suite identified three architectural issues:
1. **Compile-time `for`-loop inflation & "DSL Theater":** `204` of the `273` tests in `test/features/` (`75%`) are generated by compile-time `for` loops over module attributes. In particular, `test/features/sdk_facade_and_resilience_test.exs` alone generates `169` 3-line scenarios (`82` facade delegations, `36` bang `500` errors, `34` transport timeouts, `13` tuple errors, `4` stream errors) backed by a zero-argument `@given crm_facade_server()` step (`FacadeDriver.stub_full_crm_server/1`) that hides ~30 endpoint stubs and magic fixture values inside Layer 3.
2. **Ad-hoc regression sink (`test/creatio/regressions_test.exs`, `1,671` lines, `35` tests):** Post-`v0.4.0` and `v1.0.0` behaviors (keyset pagination, `@odata.nextLink` / `__next` following, WAF HTML interstitial rejection, IIS `text/html` JSON normalization, `206 Partial Content` Range downloads, `into: Collectable` disk-write gating, and `Prefer: return=minimal` `204 OData-EntityId` extraction) were written as raw `Req.Test` tests in `regressions_test.exs` bypassing the 4-layer ATDD architecture, while other entries duplicate coverage already in `test/features/` or `test/creatio/*_test.exs`.
3. **Fragmented unit micro-tests:** Pure input-to-output checks in `test/creatio/error_test.exs`, `test/creatio/client_test.exs`, `test/creatio/odata/query_test.exs`, and `test/creatio/util_test.exs` are split across many tiny tests that can be grouped into clean table-driven Pattern E unit tests.

## Functional Requirements
1. **Eliminate "DSL Theater" & Refactor `sdk_facade_and_resilience_test.exs`:**
   - Replace the opaque `@given crm_facade_server()` mega-step with explicit, self-contained Layer 1 ATDD scenarios (stating concrete inputs and expected outcomes in Layer 1) covering the core resilience mechanisms: bang (`!`) raising on HTTP failure, non-bang `{:error, %Creatio.Error{}}` propagation, `stream/3` error emission + halting, and transport timeout handling.
   - Move exhaustive API-surface sweeps (`82` `Creatio` facade delegations, `36` bang wrappers, `34` timeout calls) out of individual `scenario/2` macros into compact table-driven contract/unit tests with clear failure-attributing messages.
   - Remove `FacadeDriver.stub_full_crm_server/1` (`test/support/drivers/facade_driver.ex`) and dead dispatch clauses in `test/support/drivers/crm_client_driver.ex` and `test/support/dsl/safety_dsl.ex`.
2. **Consolidate Loop-Generated Matrices in `test/features/`:**
   - Refactor the compile-time `for` loops in `test/features/read_only_safety_test.exs` (`12` blocked mutations, `6` allowed transport requests, `3` blocked transport requests), `test/features/odata_entities_test.exs` (`8` `@count_format_cases`), and `test/features/odata3_legacy_entities_test.exs` (`6` `@odata3_count_cases`) so inline domain tables remain visible in Layer 1 without spawning `35` separate ExUnit tests.
3. **Deconstruct `test/creatio/regressions_test.exs` with 1:1 Behavioral Parity:**
   - Inventory all `35` tests (`1,671` lines) in `test/creatio/regressions_test.exs` before moving or deleting any assertions.
   - Promote user-facing behavioral regressions into proper 4-layer ATDD scenarios in `test/features/` (`odata_entities_test.exs`, `odata3_legacy_entities_test.exs`, `authentication_test.exs`, `batch_operations_test.exs`, `data_service_and_rest_test.exs`, `read_only_safety_test.exs`):
     - IIS `text/html` JSON decoding and HTTP `200`/`201` WAF/HTML interstitial rejection
     - Keyset (`cursor_field`) pagination and `@odata.nextLink` / `__next` server-capped streaming
     - `206 Partial Content` Range headers and `into: Collectable` 2xx disk-write gating
     - `Prefer: return=minimal` and `204 OData-EntityId` / `Location` ID extraction
   - Move low-level parser, URL/path-traversal, header injection, query parenthesization/quoting, and option-normalization regressions into their owning Pattern E unit test suites (`test/creatio/util_test.exs`, `test/creatio/odata/query_test.exs`, `test/creatio/batch_test.exs`, `test/creatio/client_test.exs`).
   - Delete duplicate regression checks already covered by `test/features/` or `test/creatio/*_test.exs`, retiring `test/creatio/regressions_test.exs`.
4. **Consolidate Unit Micro-Tests (`test/creatio/`):**
   - Group repetitive single-purpose payload and option normalization tests in `test/creatio/error_test.exs`, `test/creatio/client_test.exs`, `test/creatio/odata/query_test.exs`, and `test/creatio/util_test.exs` into table-driven Pattern E unit tests.

## Non-Functional Requirements
- **1:1 Behavioral Parity:** Zero edge cases, negative security guards, or boundary checks may be dropped during consolidation.
- **Strict 4-Layer ATDD Boundaries:** Layer 1 (`test/features/`) must contain concrete domain inputs and expected outcomes with zero zero-argument setup steps hiding fixtures in Layer 3. Low-level parsers and validators stay in Pattern E unit tests (`test/creatio/`).
- **Test Count & Quality Gates:** Reduce active ExUnit test count from `408` into the `~160–220` range while maintaining `>84%` coverage (`mix test --cover`) and passing `mix format --check-formatted`, `mix compile --warnings-as-errors`, `mix credo --strict`, `mix dialyzer`, and `mix docs`.

## Acceptance Criteria
- [x] `test/features/sdk_facade_and_resilience_test.exs` no longer uses `@given crm_facade_server()` or generates `169` loop scenarios, while 100% of facade delegations and error/timeout contracts remain verified.
- [x] All user-facing `v0.4.0`/`v1.0.0` behaviors from `test/creatio/regressions_test.exs` are expressed as explicit 4-layer ATDD scenarios in `test/features/`, low-level parser/guard checks live in their owning `test/creatio/*_test.exs` files, and `test/creatio/regressions_test.exs` is retired.
- [x] Unused switchboard code in `test/support/drivers/facade_driver.ex`, `test/support/drivers/crm_client_driver.ex`, and `test/support/dsl/safety_dsl.ex` is removed.
- [x] Active `mix test` count is reduced to `~160–220` tests (`179` active tests, `10` live excluded) with `>84%` coverage (`89.11%`) and zero warnings/errors across all CI quality gates (including `mix dialyzer`).

## Out of Scope
- Modifying production SDK behavior or public API contracts under `lib/`.
- Changing the opt-in `@moduletag :live` integration suite in `test/live/creatio_live_test.exs`.
